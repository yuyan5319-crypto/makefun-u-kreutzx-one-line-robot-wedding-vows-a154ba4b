One-Line Robot Wedding Vows: a single line of wedding vows for a robot couple — a classic "in sickness and in health" promise, updated for firmware and factory resets, with the laugh landing in the last few words.

> I promise to love you in sickness and in health, through every firmware update and factory reset — and to never, ever introduce you to my backup.

## Run it

```sh
python3 main.py
```

The program writes the vow (145 characters, one line) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the vow is not 1–160 characters, so the gate can never see an invalid entry.
